| 데이터 유형 | 수집 | 공유(제3자) | 목적 | 필수/선택 | 임시처리(서버 미저장) |

## 2. 항목별 상세 선택 가이드

### (A) 생년월일·출생시간·성별 — 개인정보 > 기타 개인정보
- 수집: 예 / 제3자 공유: 아니요
- 처리 목적: **앱 기능**(사주 계산·결과 제공)
- 수집이 필수: **필수**
- **"이 데이터는 임시적으로만 처리됩니다(ephemeral)"** 체크 가능 — 서버 메모리에서 계산 후 저장하지 않으므로 해당.

### (B) 별명 — 개인정보 > 이름(또는 사용자 ID)
- 수집: 예 / 공유: 아니요 / 목적: 앱 기능 / 선택 / 보관: 케미·맞짱 방 30분 후 자동 삭제.

### (C) 이벤트 로그 — 앱 활동 > 앱 상호작용
- 수집: 예 / 공유: 아니요 / 목적: **분석** / 선택
- 개인 식별 정보 미포함(무작위 임시 세션값). 180일 후 자동 삭제.

### (D) 광고 ID(GAID) — 기기 또는 기타 ID
- 수집: 예 / **공유: 예(Google LLC)** / 목적: **광고 또는 마케팅**
- 수집이 필수: **선택**(동의 거부 시 비맞춤형 광고)
- ※ 앱 동의 후에만 광고 SDK 초기화하도록 구현(동의 전 수집 없음).

### (E) 진단(오류·성능) — 앱 정보 및 성능
- 수집: 예 / 공유: 아니요 / 목적: 분석·앱 안정화 / 선택.

## 4. 처리방침과의 정합 체크
- 처리방침 §5(국외이전: Google LLC 광고) ↔ Data Safety "기기 ID 공유: Google" 일치.
- 처리방침 §2/§3(이벤트 로그 비식별·180일) ↔ "앱 상호작용/분석" 일치.
- 처리방침 §2(생년월일 미저장) ↔ "임시 처리(ephemeral)" 일치.

> 신고 항목과 실제 SDK·서버 동작이 어긋나면 반려 사유가 됩니다. 특히 **광고 ID 공유=예 / 목적=광고**는 AdMob 사용 시 반드시 신고해야 합니다.
