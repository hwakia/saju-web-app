## 1. 서비스 개요 및 시스템 아키텍처

- **서비스 성격:** 사주(명리) 원국 분석 및 궁합(케미)·대결(맞짱)을 **오락·참고용**으로 제공하는 안드로이드 앱. 결과는 앱 내부의 **고정 명리 계산식**으로 산출하며 **생성형 AI를 사용하지 않음.**
- **구성:**

```
Flutter 안드로이드 앱(WebView)
        │  (HTTPS)
        ▼
Streamlit Community Cloud  ── 앱 구동·사주 계산 (운영사: Snowflake Inc., 미국)
        │  (HTTPS)
        ▼
Supabase (PostgreSQL)      ── 데이터 저장 (운영사: Supabase, Inc., 미국 리전)

[광고] 앱 내 Google AdMob → Google LLC(미국)  : 광고 식별자(GAID)
[코드] GitHub(미국)        : 소스코드만 보관, 개인정보 미저장
```

- **운영자:** 국내 개인 운영자(법인 아님). 국내대리인 지정 대상 아님.
- **(미확정 표시)** Supabase 프로젝트 리전은 운영자 확인상 **미국**으로 파악함(검토 시 리전 확정 권고).

## 2. 개인정보 처리 프로세스 (단계별 상세)

### A. 사주 분석 입력 → 계산 → 결과
- **수집 항목:** 생년월일, 출생시간(또는 "시간 모름"), 성별, 양/음력, 야자시 모드, 출생지·태양시 보정 선택값, (원국 직접 입력 시) 천간·지지 8글자.
- **수집 방법:** 사용자가 앱 입력 화면에 직접 입력.
- **처리·이전:** 입력값이 **Streamlit Cloud(미국)** 서버로 전송되어 명리 계산에 사용됨. **계산 시점 서버 메모리에만 일시 존재**하며 **데이터베이스에 저장하지 않음.**
- **보유·파기:** 탭 종료·서버 재시작 시 메모리에서 소멸. 별도 저장본 없음.

### B. 익명 이용 통계 (테이블: `app_events`)
- **자동 생성 항목:** **무작위 임시 세션 식별자**(매 세션 새로 생성되는 UUID, 영속 식별자 아님), 이벤트명, 화면명, 유입 경로(source), 앱 버전, 관리자 여부 플래그, 비식별 메타데이터.
- **저장소:** Supabase(미국) `app_events`.
- **미포함:** IP, 이름, 생년월일시, 기기 식별자 등 **개인 식별 정보 없음.** 관리자 접속은 집계에서 제외. localStorage·쿠키로 방문을 영속 추적하지 않음.
- **보유·파기:** **생성 후 180일 경과분 자동 삭제**(방 정리 루틴 `sb_cleanup_expired_rooms`에 구현, 세션당 1회 실행).
- **운영자 판단:** 개인을 식별하지 않는 통계 정보로, 사실상 **비개인정보**로 판단(→ 검토 요청 7-⑤).

### C. 케미 방 · 맞짱 방 (실시간 그룹 기능)
- **저장 항목:** 별명(최대 10자), 분석 점수·강약 등급, 대표 오행. **(모임 케미 한정)** 참가자 간 케미 계산을 위해 **사주 팔자(간지)를 인코딩한 토큰**을 임시 저장.
- **저장소:** Supabase(미국) `chemistry_rooms` / `battle_rooms` / `battles`.
- **미저장:** 원본 생년월일시·성별은 저장하지 않음.
- **보유·파기:** 방 생성·참여 시각으로부터 **30분 후 자동 삭제(만료 즉시, 인코딩 토큰 포함).**

### D. 기기 로컬 저장
- 브라우저 localStorage / 앱 캐시에 **참가자 보관함**, **"내 사주 저장 링크"**(URL 쿼리에 생년월일·성별·날짜 기준 포함)가 저장될 수 있음. **기기에만 저장**되며 캐시·사이트데이터 삭제 시 제거. 서버 DB 저장 아님.

### E. 모바일 광고 (Google AdMob)
- Google LLC(미국)가 맞춤형 광고 제공을 위해 **광고 식별자(GAID)·앱 이용 이력**을 수집·처리(국외 이전). 앱 최초 실행 시 **선택 동의**로 고지하며, 미동의 시 비맞춤형 광고로 제공. 거부: Android 광고 ID 삭제/재설정.

### F. 동의 절차(앱 최초 실행 1회)
- **① 필수 동의:** 사주 분석 입력값(생년월일·시간·성별) 수집·이용 및 **미국 Streamlit Cloud로의 국외 이전**. 거부 시 서비스 이용 제한.
- **② 선택 동의:** Google AdMob 광고 식별자(GAID) 수집·이용. 미동의 시 비맞춤형 광고.
- **연령:** 만 14세 미만 이용 차단.
- (케미·맞짱 방 참여 시 별도 수집 안내 표시.)
