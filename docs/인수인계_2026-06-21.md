- **패키지명**: `com.hwakia.saju` — **절대 변경 금지(고정)**.

7. **입력 화면 직관 개편(가장 최근 작업, 완료)**:
   - 입력방식/성별/날짜기준 라벨 제거 → 옵션이 바로 노출.
   - 야자시 모드 + 내 사주 저장 한 줄로 합침.
   - 정체불명 🗑️ 아이콘 → "🗑 이 기기에 저장된 내 사주 삭제" 명확한 버튼.
   - **생년월일시 입력**: 처음엔 3칸(년/월일/시) 분리 + 자동이동을 시도했으나, **Streamlit의 blur-시 rerun + iframe 샌드박스 제약으로 자동이동이 신뢰성 없음**. 사용자 지시로 **한 칸 입력으로 복귀**(`single_birth_dt_text`, 예시 `19900520 1230`). 프리필도 한 칸 형식으로 맞춤.

> **교훈(중요)**: Streamlit에서 입력칸 간 자동 포커스 이동은 안정적으로 구현 불가. 칸 분리는 자동이동 없이 탭 이동만 가능하므로, 매끄러움이 중요하면 한 칸 통합이 현실적.

## 5. 남은 작업 (사용자 PC/콘솔에서 직접)

1. **웹 변경 push**: `git add app.py && git commit && git push` → 1~2분 후 Streamlit 반영.
2. **AAB 재빌드**: 파일 동기화 후 versionCode 올려서 빌드. (아이콘 변경 반영하려면 repo의 lib/res/assets를 빌드 폴더로 robocopy 후 `flutter clean` + `flutter build appbundle --release --build-name=1.0.14 --build-number=19` 권장.)
   - **빌드 버전 주의**: 14·15·16 이미 사용됨. 다음은 **19** 이상으로. `--build-number=N`으로 강제하는 게 가장 확실.
   - 아이콘이 안 바뀌면: 폰에서 앱 삭제 후 재설치 + 재부팅(런처 캐시).
3. **Play Console**: 새 AAB 업로드, 스토어 등록정보 갱신(Sai 이름, `store_icon_512.png`, `feature_graphic_1024x500.png`, 스크린샷), 데이터 안전성 폼 작성(`docs/play_data_safety_답변표.md` 참고).
