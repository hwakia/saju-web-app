# Sai — Play 스토어 등록정보(ASO) 초안

검색 노출을 높이기 위한 제목/설명 초안과 적용 절차. 콘솔에 그대로 복사·붙여넣기 하세요.
(키워드는 자연스럽게 배치 — 도배는 정책 위반이라 역효과)

---

## 1. 앱 이름 (최대 30자)

> **권장안 A**
```
Sai - 사주 궁합 운세
```

> 권장안 B (자리 여유 활용)
```
Sai: 사주 궁합 오늘의 운세
```

- "Sai" 단독은 검색이 안 잡히므로 핵심 키워드(사주·궁합·운세)를 제목에 포함하는 게 핵심.

---

## 2. 간단한 설명 (최대 80자)

```
사주 원국 분석부터 궁합·오늘의 운세까지. 천간합·천간충으로 풀어주는 무료 사주 앱.
```

- 검색 가중치가 높은 영역. 핵심 키워드를 한 문장에 자연스럽게.

---

## 3. 자세한 설명 (최대 4000자)

```
Sai(사이)는 사주로 나와 우리 사이를 읽는 무료 사주·궁합·운세 앱입니다.
생년월일시만 입력하면 사주 원국을 자동으로 뽑아, 천간합·천간충까지 반영한
깊이 있는 풀이를 보여드립니다.

■ 사주 진단 (원국 분석)
내 사주팔자의 구조를 한눈에. 일간을 중심으로 음양오행의 균형,
천간합·천간충, 강약을 풀어 성향과 기질, 타고난 흐름을 분석합니다.

■ 사주예보 (오늘의 운세)
오늘의 처방부터 일운까지. 그날의 천간 흐름과 내 사주의 관계를 짚어
하루를 어떻게 보내면 좋을지 가볍게 안내합니다.

■ 초대 케미 (궁합)
친구나 연인을 초대해 둘의 사주 궁합을 확인하세요.
천간합·충을 반영한 점수와 칭호로 우리 사이의 케미를 재미있게 풀어줍니다.

■ 맞짱 (사주 대결)
누구의 기운이 더 셀까? 두 사람의 사주를 맞붙여 점수로 겨루는
가볍고 유쾌한 사주 대결 콘텐츠입니다.

■ 이런 분께 추천합니다
- 무료로 정확한 사주 풀이가 궁금한 분
- 연애운·궁합, 오늘의 운세를 챙겨 보고 싶은 분
- 사주팔자, 음양오행, 천간지지를 쉽고 재미있게 알고 싶은 분

■ 개인정보 안심
생년월일·출생시간 등 민감 정보는 사주 계산에만 쓰이고 서버에 저장하지 않습니다.
케미·맞짱 방 정보도 30분 뒤 자동 삭제됩니다. 만 14세 이상 이용 가능합니다.

지금 Sai에서 내 사주와 우리 사이를 확인해 보세요.

키워드: 사주, 사주팔자, 무료 사주, 궁합, 연애운, 오늘의 운세, 무료 운세,
사주풀이, 음양오행, 천간, 천간합, 사주 궁합, 띠별 운세
```

> 맨 아래 "키워드:" 줄은 색인엔 도움되지만 보기 싫으면 빼도 됩니다(설명 본문에 이미 자연 포함됨).

---

## 4. 카테고리 & 태그

- **카테고리**: 라이프스타일 또는 엔터테인먼트 중 적합한 것.
- **태그**: 자유 입력이 아니라 **정해진 목록에서 최대 5개 선택**. 운세/사주/라이프스타일 관련으로 맞는 항목 선택.

---

## 5. 콘솔 반영 절차

1. Play Console → 해당 앱 선택.
2. 좌측 **사용자 늘리기 → 스토어 인지도 → 기본 스토어 등록정보**.
3. **앱 이름 / 간단한 설명 / 자세한 설명** 칸에 위 내용 붙여넣기.
4. (선택) **사용자 늘리기 → 스토어 설정 → 앱 카테고리**에서 카테고리·태그 지정.
5. 우측 상단(또는 하단) **저장**.
6. 스토어 등록정보 변경도 검토를 거칠 수 있어요. **관리형 게시가 꺼져 있으면 승인되는 즉시 자동 반영**됩니다(보통 앱 심사보다 빠름).
7. 반영 확인: **게시 개요** 또는 **제출 활동**에서 "스토어 등록정보" 항목 상태 확인.

> 텍스트 외에도 **설치 수·평점·리뷰·재방문율**이 검색 순위에 크게 작용해요.
> 초기 사용자에게 리뷰를 부탁하는 게 노출에 가장 효과적입니다.
