# 사주 진단 캐릭터 페르소나 — 설계도

작성일: 2026-06-25 · 상태: **설계 확정 대기(미구현)**
목적: 진단 결과 최상단과 공유 PNG에 "이 사람은 이런 사주야"를 한 방에 규정하는 **칭호 + 강렬한 한 줄**을 표시. 톤은 **센데 품위있게**.

---

## 1. 대원칙 — 진단과 100% 매칭

페르소나는 **새 시스템이 아니라, 이미 진단이 만든 `char`를 증폭**한다.

- 입력: `get_mbti_character()`가 만든 `char`(noun·adj·role·operation) + `result`.
- **자체적으로 일간/강약을 재계산하지 않는다.** (재계산하면 진단 본문과 어긋날 수 있음)
- 은유·역할 어휘는 **코드값을 그대로** 사용.
- 합충형파해·신살만 **새 변조 축**으로 추가(현재 `char`에 없으므로 모순 없이 다양성만 추가).

---

## 2. 입력 축 (모두 기존 코드에서 산출됨)

| 축 | 소스 | 값 |
|---|---|---|
| 일간 물상 (noun) | `char["noun"]` | 거목/화초/태양/불꽃/태산/대지/바위/보석/바다/맑은 물 |
| 조후·강도 (adj/tone) | `char["adj"]`, `char["tone"]` | 따뜻/서늘 등 기후 형용사 + warm/cool/mild |
| 강약 | `day_master_strength` | 극신약/신약/중화/신강/극신강 |
| 역할 (role) | `char["role"]` | 독립가/아이디어뱅크/전략가/리더/책사/밸런서 |
| 작동 (operation) | `char["operation"]` | 준비형/자기주도/흐름적응/균형/연결 |
| 합충형파해 | `detect_interactions` | 삼합·육합·방합·지지충·삼형·자형·원진 |
| 신살(흉) | `evaluate_shinsal_support` | 양인·백호·괴강·역마·원진 |
| 신살(길) | `evaluate_shinsal_support` | 천을귀인·천덕/월덕·문창·화개·도화·금여 |
| 특수격 | `detect_special_pattern` | 종왕/종강/종재/종살/종아 (칭호 통째 오버라이드) |

---

## 3. 문장 구조 — "수식 변형(modulation)"

페르소나 = **칭호 1개 + 한 줄(1~2문장)**. 슬롯에 후보 2~3개를 두고 **8글자 사주 시드**로 고정 선택(같은 사주=항상 같은 결과).

```
[칭호]  = [강도수식어 ← 강약] + [물상 ← 일간noun] + ["처럼 ~하는 사람" ← role]
[한 줄] = [관계동사절 ← 합충형파해] + [핵심결 ← role/operation] (+ [신살 수식어 1~2개])
```

핵심: ②~⑨는 ①에 **덧붙이는 게 아니라 단어를 갈아끼운다.**

### 3-1. 일간 물상 → 칭호 골격 (코드값 고정)

거목=큰 나무 / 화초=여린 풀 / 태양=한낮의 태양 / 불꽃=등불·불꽃 / 태산=큰 산봉우리 / 대지=너른 땅 / 바위=단단한 바위 / 보석=벼려진 보석 / 바다=깊은 바다 / 맑은 물=흐르는 맑은 물

### 3-1-b. 물상 "물성 차원" 변조 (은유 자체를 입체화)

물상은 고정 단어가 아니라 **2개 물성 차원(온도·크기)**으로 변형한다. 둘 다 코드에서 바로 나오는 값이라 추가 계산이 필요 없다. (깊이 차원은 통근·인성 합성이 필요해 효과 대비 복잡 → 도입하지 않음)

| 물상 | 차원1 (온도) | 차원2 (크기) |
|---|---|---|
| 맑은 물(癸) | 조후 축 | 강약·수세력 |
| 바다(壬) | 조후 축 | 강약(넓이) |
| 태양·불꽃(丙丁) | 조후·강약(세기) | 투출·격(밝기) |
| 거목·화초(甲乙) | 조후(무성함) | 강약(크기·굵기) |
| 태산·대지(戊己) | — | 강약(크기·높이) |
| 바위·보석(庚辛) | 조후·격(예리함·광택) | 강약(단단함) |

**물 차원 사전(癸·壬 공통)**
- 온도(조후 adj): 한(차분하게 구조화하는)→차가운·서늘한 / 난(활기 있게 표현하는)→따뜻한·미지근한 / 중(부드럽게 균형 잡는)→맑은 / 금국(겉부드속냉철)→겉은 잔잔하나 속은 서늘한
- 크기(강약): 극신강·신강→넓은·도도한·큰 / 신약·극신약→가는·여린·자그마한 / 중화→잔잔한

조합 예: 차갑고 큰 물 / 따뜻하게 흐르는 시냇물 / 넓고 도도한 큰 물 / 맑게 흐르는 시냇물 / 서늘하고 잔잔한 샘.

### 3-2. 강약 → 강도 수식어 슬롯

| 강약 | 수식어 후보(2~3) |
|---|---|
| 극신강 | 거침없이 타오르는 / 누구도 못 막는 / 압도하는 |
| 신강 | 자기 색이 뚜렷한 / 굳건한 / 또렷한 |
| 중화 | 균형 잡힌 / 묵묵한 / 흔들림 없는 |
| 신약 | 섬세한 / 결을 살피는 / 은은한 |
| 극신약 | 스며드는 / 맞춰가는 / 유연한 |

### 3-3. 합충형파해 → 관계 동사절 슬롯

| 상태 | 동사절 후보 |
|---|---|
| 충 우세 | 부딪치며 길을 내는 / 정면으로 돌파하는 |
| 합 우세 | 사람을 끌어안는 / 인연을 엮어내는 |
| 형(刑) | 갈등 속에 단단해지는 / 시련으로 벼려지는 |
| 원진 | 미묘한 긴장을 끌어안는 / 애증을 다루는 |
| 무난/혼재 | 묵묵히 제 길을 가는 / 흐름을 읽어 움직이는 |

### 3-4. 역할 → 핵심 결 (진단 강점과 동일 어휘)

독립가=자기 기준으로 밀어붙임 / 아이디어뱅크=발상을 구조로 / 전략가=판을 읽고 정확히 / 리더=책임을 끌어안음 / 책사=핵심을 짚어냄 / 밸런서=흐름을 조율함

### 3-5. 신살 → 수식어 (있을 때만, 최대 흉1+길1)

흉: 양인="칼날 같은 결단의" · 백호="물러서지 않는 기세의" · 괴강="범접 못 할 카리스마의" · 역마="한곳에 매이지 않는"
길: 천을귀인="귀인의 손길이 따르는" · 문창="총명함이 빛나는" · 천덕/월덕="하늘이 돕는" · 화개="고독을 벗 삼는" · 도화="사람을 끌어당기는"

**적용 규칙 (강제)**
- 동시에 여러 개면 **흉 1개 + 길 1개까지만** 문장에 삽입.
- 우선순위 — 흉: 양인 > 괴강 > 백호 > 역마 / 길: 천을귀인 > 천덕·월덕 > 문창 > 화개 > 도화. (같은 계열 다발이면 상위 1개만)
- **`evaluate_shinsal_support.hits`로 감지된 신살은 반드시 한 줄에 절로 반영**한다(태그만 달고 문장에서 누락 금지 — 이전 검토에서 발견된 오류).
- 신살이 하나도 없으면 신살 절은 생략(억지 삽입 금지). 다양성은 온도·크기·역할·합충·시드로 충분.

### 3-6. 특수격(종격) → 물상 유지 + 의미 얹기 (통째 교체 금지)

특수격이어도 **물상 골격(맑은 물·태양 등)은 유지**하고, 그 위에 격의 의미만 얹는다. (통째 교체하면 다른 일간과 톤이 따로 놀아 어색함 — 10번 사례 교훈)

- 종왕/강 = 거스를 수 없는 큰 흐름 → 예: "누구도 못 막는 도도한 큰 물"
- 종재 = 재물의 흐름을 타는 → 예: "재물의 물길을 타는 맑은 물"
- 종살 = 압박을 힘으로 바꾸는 → 예: "거센 물살을 힘으로 바꾸는 큰 물"
- 종아 = 재능을 쏟아내는 → 예: "막힘없이 쏟아지는 큰 물줄기"

---

## 4. 노출 위치

- 진단 결과 **최상단 히어로**: 이름 아래 칭호 배지 + 한 줄.
- 공유 **PNG 진단 카드** 상단: 동일 칭호 + 한 줄.
- 기존 `char["title"]`과 **같은 은유 계열**이라 동시 노출해도 따로 놀지 않음.

---

## 5. 다양성 보장

- 필수 변조 축: **강약 + 역할(십신) + 합충 상태** (신살은 보조 — 없는 사주가 많으므로).
- 한 일간 안에서도: 강약5 × 역할5 × 합충6 × (신살) × 시드 → 수백~수천 갈래.
- 시드는 **8글자 간지** 기준 → 닉네임 무관, 같은 사주 = 같은 캐릭터(랜덤 아님).

---

## 5-b. 후처리 규칙 (구현 단계)

라인 텍스트를 일일이 안 바꾸고, 선택 후 후처리로 단조로움을 줄인다.

1. **문장 끝 어미 변주** — 라인 말미의 "~사주여"가 반복되면 단조로움. 시드로 일부를 `사주여 / 팔자여 / 성미여 / 것이여` 중 하나로 치환(같은 사주는 고정). 의미 안 바뀌는 어미만 대상.
2. **호칭 빈도 게이트** — "이놈아 / 이것아"는 줄당 최대 1회, 전체의 30~40%에만 노출(시드 기반). 칭호 한 줄 + 종합 소견이 한 화면에 겹칠 때 호칭이 과하지 않게.
3. **절 조립 예산** — §3-5/3-6 + 위트풀 규칙대로 역할 위트 + 최대 2절. 호칭·어미 후처리는 절 합산 뒤 마지막에 적용.

## 6. 톤 가이드 (욕쟁이 할매 — 정겹고 투박)

- 비속어·유행어 금지, 문어체·단정형("~한 사람", "~지킨다").
- 은유 유지, 한 줄은 1~2문장.
- 케미/맞짱의 장난 드립과 결을 구분(진단은 본인이 정독하는 화면).
