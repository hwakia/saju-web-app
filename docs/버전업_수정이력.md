## 앱(Flutter) 측 수정 — saju_mri

1. **동의 화면**(consent_screen.dart): 내용이 길어 동의 버튼이 화면 밖으로 밀려
   테스터가 진행 불가 → 스크롤 가능 구조로 변경.
2. **스플래시 제거**(main.dart): 2초 강제 로딩 화면 삭제, 앱 시작 시 동의 여부에
   따라 바로 분기.
3. **뒤로가기**(home_screen.dart): 시스템 뒤로가기 → WebView 히스토리 뒤로가기,
   루트에서만 종료 확인. 종료 시 전면광고 제거(AdMob 정책 소지), "처음 화면으로"
   버튼 추가. 실제로 종료 안 되던 버그 수정(SystemNavigator.pop).
4. **연결 복구**(home_screen.dart): 백그라운드 복귀 시 끊긴 연결 자동 새로고침,
   광고·이미지 등 부속 리소스 오류로는 오류 화면 띄우지 않도록 수정.
5. **광고 빈도**: 페이지 로드 5회→10회마다 전면광고.
6. **앱 아이콘/스플래시**: MRI 흔적 제거 후 음양 디자인으로 전 해상도 교체(31개 자산).
   최종 비비드 글래스 음양 + 적응형 테두리 수정.
7. **앱명**: AndroidManifest 라벨, main.dart title, 로딩/종료 문구, pubspec
   description 모두 사주끼리로 변경.

## 웹(app.py) 측 수정 — push로 즉시 반영

1. **네비/탭 버튼 가로 배열**: st.columns가 WebView에서 세로로 쌓이던 문제 →
   st.segmented_control로 교체(네비·결과탭·케미탭).
2. **내 사주 불러오기**: 브라우저 재시작 후에도 유지되도록 localStorage 기반으로
   재구현(streamlit_js_eval), 기기 저장 삭제 버튼 추가.
3. **모임케미 공유 링크 오류**: iframe 내부에서 nullsrcdoc 주소가 만들어지던
   버그 7곳 → 실제 앱 주소로 수정.
4. **1:1 케미 결과 빈 화면**: 2명 케미 결과를 그리는 분기가 코드에서 유실되어
   네비만 나오던 버그 복원.
5. **종합예보 일운**: 월운까지만 다루던 것을 일운(오늘) 독립 문단 신설
   (간지·오행·용신 방향·당일 합충 신호 포함).
6. **4운 합충 탐지 보완**: 형(刑)·해(害)·파(破) 탐지 추가(축술형·유술해 등),
   삼합 신살(역마·도화·화개)을 일지+년지 이중 기준으로.
7. **신살 보강**: 현침·양인·괴강·백호 추가(표시용), 종합소견에서 신살 전체 표시.
8. **용신/기신 모순 수정**: 같은 오행이 용신·기신에 동시에 뜨던 문제 →
   조후가 급한 겨울·여름생만 조후 우선, 평시엔 억부 우선.
9. **오행 칩 가독성**: 글자색 충돌 → 다크 배경+밝은 오행색, 한 줄 고정 배치.
10. **시인성 개선**: 전역 보조 텍스트 색 260여 곳 밝게(대비 강화).
11. **친근체 설명 개선**: 체질·주성분·신강약·결핍 문구 20개를 생생한 비유로,
    주석의 "할머니" 표기 정리.
12. **만료 방 자동 삭제**: 케미방/맞짱방/맞짱결과 만료 1시간 후 자동 정리.
13. **개인정보 처리방침 닫기 버튼** 추가(화면 갇힘 해결), 첫 화면 업데이트 공지 제거.
14. **앱명**: 페이지 타이틀·메인 제목·처리방침 서비스명을 사주끼리로
    (기능명 "맞짱"은 유지).
